# 經文快手｜聖經趣味多人競賽

Node.js + Express + Socket.IO 即時多人聖經遊戲，支援 Render 部署。

## 三種玩法
1. **逐字揭曉**：主持人畫面逐字顯示經文，玩家手機只輸入正確出處。每位玩家每題只能提交一次；第一位答對者先取得較高速度分，其他尚未作答的玩家仍可繼續搶答。答對基本分從 100 分開始，每秒減 5 分，最低 10 分；連勝有額外加分。
2. **9×9 經文尋字**：主持人畫面顯示出處，玩家在自己的 9×9 字格中依序點選字元拼出經文；各玩家字格和選取狀態獨立；每位玩家每題只能提交一次，即使有人先拼對，其他尚未提交的玩家仍可繼續搶答。
3. **聖經生存淘汰賽**：玩家加入時填寫隊伍名稱；每隊起始 60 秒，所有隊伍從同一時間點開始倒數，各隊以獨立截止時間計時，答對後只延長本隊 10 秒，不會重設其他隊伍的計時。系統隨機選出每隊當前答題者；答對切換下一題並隨機選出下一位答題者，答錯可繼續嘗試且倒數不停；倒數歸零淘汰，最後存活隊伍獲勝。

## 題庫格式
可一次選取多份 JSON、CSV 或 TXT 匯入。每題需要經文內容、正確出處，別名可選填。CSV/TXT 每行格式：`經文內容,正確出處,別名`。JSON 可用陣列或 `{ "questions": [...] }`。

## 本機執行
```bash
npm install
npm start
```
瀏覽器開啟 `http://localhost:3000`。

## Render 部署
- New Web Service，連接 GitHub repository。
- Build Command：`npm install`
- Start Command：`npm start`
- Node 版本需 18 或更新版本。
- 部署後可用 `/health` 檢查服務是否回應。

## 注意事項
- 房間狀態目前存在伺服器記憶體；Render 服務重啟後，進行中的房間會清除。
- QR Code 使用外部 QR 圖片服務；若圖片服務不可用，仍可複製加入連結或手動輸入房間代碼。
