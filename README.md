# 經文快手 Bible Quiz Party

活潑團契風的即時多人聖經經文搶答網站。使用 Node.js、Express 與 Socket.IO。

## 功能
- 主持人建立房間代碼
- 玩家使用不同手機／電腦輸入代碼加入
- 自訂人數上限（最多 20 位玩家）、玩法與逐字揭曉速度、每題分數
- 可切換「逐字揭曉」或「完整經文立即顯示」兩種玩法
- 主持人自行建立題目、正確出處與可接受別名
- 經文題目只傳給主持人；玩家裝置不會收到經文內容
- 玩家輸入經節出處；第一位正確者取得該題分數並結束本題
- 即時排行榜、下一題、揭曉完整經文、重設分數
- 內建範例題目可快速測試

## 本機啟動
需要 Node.js 18 或更新版本。

```bash
npm install
npm start
```

瀏覽器開啟 http://localhost:3000 。

## 如何讓不同手機一起玩
所有裝置必須能連到同一個伺服器網址：
- 同一 Wi-Fi 測試：在電腦啟動伺服器，手機開啟電腦的區域網路 IP，例如 `http://192.168.1.10:3000`。請允許防火牆通過該連線。
- 不同網路／正式使用：將此專案部署到支援 Node.js、WebSocket 或 Socket.IO 長連線的主機，取得公開 HTTPS 網址，再分享給玩家。

## 重要說明
- 這是可執行的完整應用程式起始專案，但尚未部署到公開網域。單靠下載檔案不會自動產生可供所有人連線的網站；需要先在電腦或雲端主機啟動伺服器。
- 房間與分數目前存在伺服器記憶體中；伺服器重啟後會清空。若要長期營運，建議加入資料庫、主持人驗證、重新連線恢復、濫用防護與 HTTPS 部署。
- 答案以主持人輸入的正確出處／別名作標準，會忽略大小寫、空白及常見標點，但不會自動判斷所有聖經縮寫。建議在「可接受的別名」中加入常見寫法。
- 若有多位玩家幾乎同時答對，伺服器最先收到的正確答案得分。


## 功能更新
- 經文內容只傳送給主持人；玩家端只提供答案輸入、回饋與排行榜。
- 建立房間後顯示 QR Code，掃描後自動帶入房間代碼。
- 可多選匯入 JSON、CSV、TXT 題庫，匯入後需按「儲存／同步題庫」。
- 計分：起始 100 分，每秒遞減 5 分，最低 10 分；連續答對每題額外 +10 分，答錯會中斷連勝。
- CSV/TXT 每行欄位順序：經文內容、正確出處、別名（可省略）；JSON 使用 text、reference、aliases 欄位。
