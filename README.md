# 經文快手｜聖經趣味多人競賽

Node.js + Express + Socket.IO 即時多人聖經遊戲，支援 Render 部署。

## 五種玩法
1. **逐字揭曉**：主持人畫面逐字顯示經文，玩家手機只輸入正確出處。每位玩家每題只能提交一次；第一位答對者先取得較高速度分，其他尚未作答的玩家仍可繼續搶答。答對基本分從 100 分開始，每秒減 5 分，最低 10 分；連勝有額外加分。
2. **9×9 經文尋字**：主持人畫面顯示出處，玩家在自己的 9×9 字格中依序點選字元拼出經文；各玩家字格和選取狀態獨立；每位玩家每題只能提交一次，即使有人先拼對，其他尚未提交的玩家仍可繼續搶答。
3. **聖經生存淘汰賽**：每位玩家獨立存活計時，系統隨機選出一位玩家答題。玩家從題庫的三個經文出處選項中選出正確答案；答錯可繼續選，答對增加 5 秒並切換下一題及隨機選出下一位玩家。跳過題目會扣除 15 秒；時間歸零即淘汰，最後存活的玩家獲勝。生存淘汰賽題庫至少需要 3 個不同的經文出處。
4. **經文表情猜出處**：主持人畫面顯示依經文內容產生的 Emoji 線索，玩家從三個經文出處中選出正確答案。
5. **經文逐步填空**：主持人畫面先顯示少量經文字詞，其餘以空格遮住，之後每秒逐步揭曉更多字詞；玩家手機從三個經文出處中選擇答案。每位玩家每題只能作答一次，正確答案等所有玩家作答完畢後才顯示。此模式需要至少 3 個不同的經文出處。

## 題庫格式
可一次選取多份 JSON、CSV 或 TXT 匯入。每題需要經文內容、正確出處，別名可選填。CSV/TXT 每行格式：`經文內容,正確出處,別名`。JSON 可用陣列或 `{ "questions": [...] }`。

## 本機執行
```bash
npm install
npm start
```
瀏覽器開啟 `http://localhost:3000`。

## Render 部署
- New Web Service，連接 GitHub repository。
- Build Command：`npm install`
- Start Command：`npm start`
- Node 版本需 18 或更新版本。
- 部署後可用 `/health` 檢查服務是否回應。

## QR Code 加入房間
- 三種遊戲模式建立房間後，都會顯示同一種加入 QR Code。
- QR Code 由伺服器內的 `qrcode` 套件產生，不依賴第三方 QR 圖片網站。掃描後會開啟部署網站並預填房間代碼；玩家再輸入暱稱並按「加入遊戲」。
- 若掃描後未自動加入，這是預期的安全流程；仍需按「加入遊戲」。也可使用「複製加入連結」或手動輸入房間代碼。

## 注意事項
- 房間狀態目前存在伺服器記憶體；Render 服務重啟後，進行中的房間會清除。


## 生存淘汰賽玩法更新
- 系統會從已加入的玩家中隨機選出一位答題玩家。
- 只有目前答題玩家的個人剩餘時間倒數；其他玩家時間保持不變。
- 答對後切換到下一題，並隨機選出下一位答題玩家。
- 答錯可繼續嘗試；按「跳過題目」會跳到下一題並扣除目前玩家 15 秒。
- 個人時間歸零即淘汰；若跳過後時間歸零也會淘汰並選出下一位玩家。

### 經文尋字方格尺寸
建立房間前選擇「經文尋字」模式，可在「調整尋字方格大小」選擇 9×9、7×7 或 5×5。題目有效字元數需符合所選方格容量（分別為 81、49、25 格）。玩家加入房間或本題結束時，等待畫面會清除上一題的方格與已選字元，避免殘留上一題狀態。


### 新增遊戲模式：搖一搖經文配對

- 玩家手機搖一搖（或按畫面按鈕）抽取經文出處／經文內容線索。
- 每輪玩家兩兩配對，同一組會拿到互補的經文線索。
- 輸入配對玩家姓名；輸入錯誤扣 30 分，雙方都正確確認後各得 100 分。
- 全部配對完成後，玩家再搖一搖準備下一輪；為避免玩家重複配對，所有在線玩家需完成本輪並準備好才會重新配對。
- 主持人倒數 3 分鐘，時間到自動結束並按分數排名。開始遊戲需至少 2 位玩家，且在線玩家數必須為偶數。
